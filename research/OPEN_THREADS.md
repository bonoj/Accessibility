# Open Threads

Status: open research note  
Date: 2026-09-27

These are questions worth preserving before the first executable probe. They are not requirements.

## Construction from negative space

What is the smallest apparatus in which a person can talk, point, select, or otherwise cause an incomplete idea to become a concrete entity?

Could the initial world be little more than:

- space;
- loci;
- entities;
- relationships;
- a model-mediated construction seam?

How much vocabulary should exist before the first user creates anything?

What happens if the apparatus begins almost empty and is allowed to earn its interaction grammar through actual construction?

## Low floor, high ceiling

Can the same environment support an extremely easy first meaningful action and later support sophisticated executable systems?

Where do conventional "simple" interfaces accidentally impose a low ceiling?

Can complexity migrate into the constructed world while the interface remains comparatively sparse?

How do we know when progressive disclosure is revealing useful power versus merely hiding an increasingly conventional application underneath?

## Accessibility beyond modality

Voice may reduce some barriers while introducing others.

What combination of interchangeable or redundant interaction channels lets a person continue constructing when any one channel becomes expensive, inconvenient, inaccurate, or unavailable?

Can touch, speech, coarse pointing, text, spatial reference, history, and model inference cooperate without requiring the user to manage modes explicitly?

## Extreme text

What happens when readable text must become staggeringly large?

Can all consequential textual operations survive extreme enlargement through reflow, focus, paging, spoken output, or temporary full-screen reading surfaces?

Which information belongs in a spatial world and which should move to an accessible language layer?

Can a construction environment remain fully capable when only a very small amount of text fits on screen at once?

## Reference without precision

Can a person refer naturally to a semantic entity without acquiring an exact selection technique?

Examples worth eventually probing include:

- "that big one";
- "the thing on the left";
- "the controller";
- "this";
- "the thing we made yesterday";
- a coarse tap near an object.

How should ambiguity be surfaced without making every reference expensive?

Can stable semantic identity let multiple imperfect reference channels converge on the same thing?

## Interruption and recovery

What happens when construction is interrupted frequently?

Can the environment make current state, recent change, and available next action recoverable without requiring the person to remember a long interaction history?

How little working memory should the interface demand?

Can a model carry low-salience continuity without silently changing consequential intent?

## Conversational construction

What should a model be allowed to concretize autonomously from an incomplete statement?

When should it create the smallest plausible entity and let executable inspection correct it rather than asking a clarifying question first?

How should undo and correction work when the primary operation was conversational rather than a precise UI command?

Can the person say "no, not like that" and recover cheaply?

## ELI5 extensibility

Can an environment be understandable enough to begin without technical vocabulary while remaining structurally honest about what it is doing?

Can concepts acquire names only when the names become useful?

Can a person extend a system they do not know how to program without being trapped inside a preauthored catalog of allowed behaviors?

What does "extension" mean when the model can change implementation underneath the interaction surface?

## Forkable extensibility

Accessibility may provide an independent descendant for a question already preserved in World Lab research:

Can semantic knowledge and executable practice travel between projects without requiring implementation forks or duplicated source?

If Accessibility earns a generally useful interaction mechanism, can that discovery return to World Lab, Foundry, Digital Familiar, or another descendant without importing Accessibility's entire ontology?

Conversely, can Accessibility inherit useful mechanisms while remaining free to reject the assumptions that originally produced them?

## Evidence

What counts as evidence that an interaction is more accessible?

Task completion alone may be insufficient.

Possible observations include friction, recovery cost, precision demanded, number of prerequisites, ability to continue after interruption, amount of human attention consumed by interface operation, and whether expressive capability remains available as accommodations increase.

These are candidates for investigation, not a metric set.

## First probe

A promising first probe is deliberately under-specified:

> Can a person begin with an almost-empty space, express an incomplete idea through whatever interaction is easiest, and progressively make it into a small concrete executable system without first learning the apparatus?

The first implementation should make this question sharper rather than pretending it has already answered it.
